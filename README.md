# ГОРТИГ — 6-р ангийн геометр байгуулалт

Сурагч **гар утсандаа бие даан сурах, тоглоом ба тестээр давтах** офлайн PWA апп.
Дизайн технологи VI анги, Бүлэг I (Дизайн, зураг зүй).

## Дөрвөн хэсэг

| Хэсэг | Юу вэ |
|---|---|
| 📐 **Сурах** | 8 байгуулалт, алхам бүрээр анимацтай. Зураг дээр дарахад дараагийн алхам гарна. «Автомат» товч өөрөө урсгана. |
| 🎮 **Тоглоом** | «Хэдэн градус?» (төв өнцөг, 10 асуулт) · «Алхмаа эмхл» (алхмыг дараалалд оруулах) · «Аль нь зөв бэ?» (жигд байгуулалтыг олох, 8 тойрог) |
| ✍ **Тест** | 15 асуулт, санамсаргүй дараалалтай. Дүнг VIII түвшний шкалаар харуулна. |
| ⭐ **Ахиц** | Үзсэн байгуулалт, тоглоомын дээд оноо, тестийн дүн. Утсанд хадгалагдана. |

## Агуулга

Байгуулалт бүр **сурах бичигт тулгагдсан**:

| Байгуулалт | Эх сурвалж |
|---|---|
| Хэрчмийг 2 тэнцүү хуваах | Гортигийн үндсэн байгуулалт |
| Хэрчмийг 5 тэнцүү хуваах | Зэрэгцээ шулууны арга |
| Тойргийг 3 тэнцүү хуваах | Хүснэгт 1.3 (х.15) |
| Тойргийг 6 тэнцүү хуваах | Хүснэгт 1.5 (х.18) |
| Тойргийг 12 тэнцүү хуваах | Хүснэгт 1.6 (х.20) |
| Тойргийг 5 тэнцүү хуваах | Дизайн, технологийн багш нарын холбооны арга |
| Өнцгийг тэнцүү хуваах | Хүснэгт 1.9 (х.23) |
| Тойргийг 8 тэнцүү хуваах | 1.6 (х.23) |

Зургийг **томьёогоор** боддог — цэг гараар байрлуулаагүй тул таван өнцөгт, зургаан өнцөгт бүгд жинхэнэ жигд гардаг.

## Ажиллуулах

```
node tools/serve.js
```
→ http://localhost:5176

`index.html`-ыг шууд давхар дарж бас нээж болно (офлайн кэш ажиллахгүй, бусад нь бүгд ажиллана).

## Утсанд суулгах

1. **Нэг Wi-Fi сүлжээнд:** компьютер дээрээ `node tools/serve.js` ажиллуулаад, утсаараа `http://<компьютерийн IP>:5176` руу орно.
2. **Интернэтэд байршуулбал** (Vercel, GitHub Pages гэх мэт) — хөтчийн цэснээс «Нүүр дэлгэц рүү нэмэх» дарахад апп шиг суудаг. Офлайн ажиллана.

> Service worker (офлайн кэш) нь зөвхөн `https://` эсвэл `localhost` дээр ажилладаг. Файлын хаягаар (`file://`) нээвэл кэш идэвхжихгүй, бусад нь хэвийн.

## Файлууд

```
index.html            бүтэц ба доод цэс
styles.css            загвар (утасны дэлгэцэд зориулсан)
data.js               8 байгуулалт, 15 тестийн асуулт, шкал
draw.js               геометр ба SVG зурагч
app.js                дэлгэцүүд, тоглоом, ахицын бүртгэл
sw.js                 офлайн кэш
manifest.webmanifest  апп болж суух тохиргоо
icons/                192, 512, maskable
tools/serve.js        локал сервер
tools/make-icons.js   дүрсийг SVG-ээс PNG болгох (sharp)
```

Дүрсийг дахин үүсгэх: `node tools/make-icons.js`

## Ахицын өгөгдөл

Сурагчийн ахиц `localStorage`-д (`gortig_v1` түлхүүр) хадгалагдана — зөвхөн тухайн утсанд, хаашаа ч илгээгдэхгүй. «Ахиц» хэсгээс устгаж болно.
